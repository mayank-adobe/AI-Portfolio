# Week 1 Day 2

## Training Data

Information used to teach a model.

Examples:
- Books
- Articles
- Documentation
- Code

## Pre-Training

The learning phase where the model learns patterns from data.

## Model

The result of training.

Examples:
- GPT
- Gemini
- Claude
- Llama

## Prompt

The instruction given by the user.

Example:
Create a project plan.

## Response

The output generated by the model.

## Pre-Training vs Inference

Pre-Training:
Learning phase.

Inference:
Using the trained model to answer requests.

## Flow

Training Data
↓
Pre-Training
↓
Model
↓
Prompt
↓
Response

## My Understanding

The LLM learns patterns during pre-training and then uses those learned patterns during inference to generate responses based on user prompts.
